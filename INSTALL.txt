edu-pack — how to install

macOS will not run install.command when it is double-clicked, because the file is
not signed by an identified developer. This is Gatekeeper operating as designed,
not a fault in the download. Two methods avoid it.

Option A — ask DeepSeek Harness to install it

This requires no Terminal and no change to your security settings.

1. Unzip the download by double-clicking the zip.
2. Open DeepSeek Harness and start a new chat.
3. Paste this and press Return:

   Install the edu-pack skills from the zip in my Downloads folder.

DeepSeek Harness runs commands directly rather than through Finder, so the
security check does not apply. It may ask for permission to write into ~/.dsh.

Option B — one command in Terminal

1. Open Terminal: press Command and Space, type Terminal, press Return.
2. Paste this line and press Return:

   xattr -d com.apple.quarantine ~/Downloads/edu-pack*/install.command

3. Double-click install.command.

If the folder is not in Downloads, replace ~/Downloads/edu-pack* with its actual
path.

Neither method is acceptable as a permanent answer. The correction is for this
project to sign and notarise the installer, which requires an Apple Developer
account. Until then, use one of the two methods above.
